# 知识时效与台账

## 两个时间概念

`valid_from` 与 `valid_to` 描述文档事实的有效区间，检索按 `as_of` 判断可见性。Answer 的 `knowledge_as_of` 是本次实际引用文档中最早的 `valid_from`；没有引用时为 null，表示不适用，而不是“最新”。

## 过期与替代

被替代的文档会把 `valid_to` 设为替代时间，因此当前时刻查询看不到旧版本；传入更早的 `as_of` 可以复现当时可见的版本。`superseded_by` 保留版本链，便于审计。

## 模型事实

模型的版本、价格、能力与发布状态属于时效敏感事实，不得从参数记忆或示例文档推断。统一查 knowledge-freshness 台账，机器可读投影为 `knowledge/model-ledger.yaml`，每条带 `source_url`、`verified_at` 与 `expires_at`。

台账过期时回答应带 `model_ledger_stale`，无条目时返回 `knowledge_gap`，都不得给出确定性价格或版本。外部查找只补充公开事实，不能绕过租户与 ACL。

## 输出口径

引用模型事实的回答必须能定位到来源与核实时间；定位不到时，应以“证据不足”表达，而不是用流畅叙述补齐。
