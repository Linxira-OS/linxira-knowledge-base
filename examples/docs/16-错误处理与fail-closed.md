# 错误处理与 fail-closed

## 错误分类

存储层错误分为数据库错误、序列化错误、FTS5 不可用、记录冲突、输入非法与未找到。检索遇到 FTS5 不可用时，把它转成 `keyword_unavailable` 降级并继续；其他存储错误向上返回，不被吞掉。

## HTTP 状态

Web 层把错误映射为 JSON `{"error": "...", "message": "..."}`：未认证 401，无权限 403，输入非法 400，未找到 404，冲突 409，内部或存储故障 500。检索路径遇到 FTS5 不可用会转成 `keyword_unavailable` 降级；只有未被就地处理的存储错误才返回 500。

## 批量导入

单个文件失败不会中断整批：失败项进入 `failed` 列表，成功的继续写入，最后 `failed` 非空时退出码为 2。这样 CI 能区分“部分成功”和“全部成功”。

## fail-closed

身份或 ACL 无法确认时一律拒绝：ACL JSON 解析失败、租户不匹配、令牌过期都返回 401/403 或剔除候选。没有任何路径会在权限未知时回退到 allow-all。
