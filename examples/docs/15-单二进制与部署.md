# 单二进制与部署

## 进程形态

LKB 编译为一个名为 `lkb` 的 Rust 二进制，HTTP 层用 axum，数据访问用 sqlx。solo 不依赖任何外部语言运行时或解释器，也不要求 Docker；运行期只有二进制、配置和 SQLite 文件。

## 默认布局

solo 默认绑定 `127.0.0.1:7331`，数据库为 `data/lkb.sqlite`，可用 `LKB_SQLITE_PATH` 改路径。`lkb serve` 启动服务；`lkb config check` 先确认生效配置。

## 健康检查

`GET /health` 返回 `status`、`profile`、`backend` 与 `fts` 四个字段。数据库可用时状态为 ok；存储探测失败返回 503 与 `storage_unavailable`，不会把故障伪装成正常。

## 绑定与身份

非回环地址必须启用认证，否则启动被拒绝。team 与 enterprise 使用 PostgreSQL，连接串放在 `url_env` 指向的环境变量中，不写进配置文件。

部署时先放二进制与配置，再执行迁移与导入；示例仓库不承诺冷启动时间或吞吐数字。
