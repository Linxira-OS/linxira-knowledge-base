# 导入导出

## 输入

`lkb import <path>` 接受目录或单个 `.jsonl` 文件。目录扫描支持的扩展名为 md、markdown、txt、html、htm；PDF 只有构建启用 `pdf` feature 时才解析，否则记为 skipped。隐藏文件、符号链接和不支持的扩展名都会被跳过并记录原因。

## JSONL 字段

每行必须有 `path` 与 `content`；可选 `title`、`mime`、`space`、`acl`、`valid_from`、`valid_to`、`version`、`content_hash`、`source_uri`。治理字段也可以放在 `metadata` 对象里。

## 报告

导入报告给出 `imported`、`skipped`、`failed` 计数，以及每条跳过或失败的原因和 warning。`--json` 输出机器可读版本。`failed` 非空时进程以退出码 2 结束，但已成功的文件保留。

## 导出

`lkb export` 输出 JSON Lines，每条包含 doc_id、path、title、content、space、mime、content_hash、raw_hash、acl、有效期、version、status 与 source_uri；`--out` 写文件，缺省写标准输出。导出再导入空库应保持 doc_id 集合一致。

同一目录重复导入是幂等的：内容未变化的条目计入 skipped，而不是新增版本。
