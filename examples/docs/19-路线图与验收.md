# 路线图与验收

## P1 范围

P1 的目标是用 Rust 单二进制跑通 solo 闭环：Markdown/PDF 摄入、FTS5 BM25 检索、可选 hybrid、带引用回答、CLI 与本地 Web、最小 Wiki、认证与导入导出。

本示例集就是 P1 的评测素材：20 篇 Markdown 加 20 条问题，每条问题标注正确文档路径。

## 出口标准

关键可执行标准包括：

- 20 条问题中，正确答案所在片段进入前 5 条召回的比例不低于 0.8；
- 20 条回答的引用都能解析到源文件与行号，且该位置文本包含答案；
- 默认配置断网可完成摄入、检索与回答，不产生外部请求；
- 删除索引后重建，doc_id 集合一致；
- 能力未启用或不可用时，`degraded[]` 如实声明；
- 重复导入幂等；未认证请求 401，缺 CSRF 的写请求 403；
- 非回环地址配免认证时拒绝启动；导入导出计数正确；
- 干净目录只放二进制与配置即可启动。

## 口径

路线图明确未编译验证时不得宣称通过；指标必须绑定数据集、配置与索引代次。逐条标准见 `document/roadmap.md`。
