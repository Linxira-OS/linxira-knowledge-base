# 治理字段

## 治理信封

documents 与 chunks 都带同一组治理字段：`tenant_id`、`space_id`、`acl_json`、`acl_principals`、`valid_from`、`valid_to`、`version`、`superseded_by`，documents 另有 `status`（active / superseded / orphaned / deleted）。

solo 档不省略这些字段，而是填入固定值：租户 `t_local`、空间 `s_default`、ACL allow-all。这两个常量在配置归一化时强制写入，改配置文件也不会生效。

## ACL 的两种形态

`acl_json` 是权威输入：`{"mode":"allow_all",...}` 或 `{"mode":"allow_list","users":[...],"groups":[...],"version":1}`。

`acl_principals` 是给召回 SQL 用的紧凑索引键：allow-all 为 `|*|`，allow-list 为 `|u:alice|g:eng|`。两者必须同时写入，否则召回过滤与进程内校验会不一致。

## 有效期与版本

`valid_from` 是事实生效时间，`valid_to` 为空表示没有已知失效时间，查询按开放区间处理。`as_of` 早于 `valid_from`，或 `valid_to` 已过期，记录都不进入候选。

内容变化生成新 doc_id，旧记录 `status` 变为 superseded、`superseded_by` 指向新 id，并把旧记录的 `valid_to` 设为替代发生的时间。`version` 在替代时取旧版本加一。
