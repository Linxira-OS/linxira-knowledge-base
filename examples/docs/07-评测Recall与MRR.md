# 评测 Recall 与 MRR

## 数据集

评测集是 JSON Lines，每行至少包含 `query` 与 `expected_paths`，也可以给 `expected_doc_ids`。`expected_paths` 写源文件逻辑路径，例如 `docs/06-文档身份与重建.md`。

## 执行

`lkb eval <dataset> --k 5 --mode bm25` 对每条问题调用同一检索内核。默认 k 为 5，默认模式为 bm25，保证离线可重复。报告包含数据集、问题数、Recall@K、MRR 与逐条结果。

## 指标定义

对每条问题，取前 K 条命中中第一个匹配期望路径或 doc_id 的名次 r。

Recall@K 是“是否命中”的均值：命中记 1，未命中记 0，不是命中条数除以 K。MRR 是 1/r 的均值，未命中记 0。第一条命中贡献 1.0，第二条 0.5，第五条 0.2。

路径比较前会统一小写、把反斜杠换成斜杠、去掉开头的 `./`，并允许一侧是另一侧的后缀，以兼容不同导入根目录。

## 可归因

指标必须绑定数据集、配置与索引代次。降级基线与全能力基线分开记录，否则指标变化无法归因。
